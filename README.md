# Overthink Overbuy ($OTOB) website design and asset package

This package is a self-contained design handoff for a later Cursor website build. It contains approved branding, production illustrations, social art, twelve page/section mockups, complete website copy, design rules, route/asset mapping, and an asset manifest.

## Start here
1. Read `brand-info.txt` and `content/website-copy.md`.
2. Review `specs/design-guide.md` and `specs/page-and-asset-map.md`.
3. Compare the numbered mockups in `previews/` with their captions in the page map.
4. Build one responsive page at `/` with anchors `#hero`, `#story`, `#token-info`, `#how-to-buy`, `#community`, `#faq`.
5. Use live HTML text for headings, buttons, navigation, data and disclaimers. Place artwork from the exact paths in the asset map.
6. Replace bracketed placeholders only with confirmed information; keep associated links/actions disabled until then.

## Project direction
Name: Overthink Overbuy. Ticker: $OTOB. Hook: “Two voices. One wallet.” The trader’s research-minded professor and rocket-happy daredevil create an instantly readable trading joke. Celebrity-inspired imagery is fictional parody with no implied endorsement.

## Assets and source notes
- The circular logo, 3:1 banner, and 1100x520 Telegram banner are approved assets reused from the prior brand package.
- Production character art, share image, and page previews are original image-generation outputs for this design. Character cutouts and the logo use PNG alpha; the manifest records image dimensions and transparency.
- Favicon sizes are derived from the approved circular logo; the simple interface icons are project-authored SVG.
- Recommended self-hosted web fonts: Fredoka and Nunito Sans through npm packages `@fontsource/fredoka` and `@fontsource/nunito-sans`. The site does not require external image requests.
- Reference inspiration only: official Dogecoin https://dogecoin.com/ and its Dogepedia https://dogecoin.com/dogepedia/articles/what-is-dogecoin/; official Shiba Inu https://shib.io/ and https://shib.io/ecosystem. The PEPE reference https://pepe.vip/ could not be accessed for review. No reference assets are included or copied.

## Checks and limits
All included PNGs were opened and dimension-checked during packaging; required banner sizes and transparent logo/artwork are verified. Review `assets-manifest.csv` for details. Previews are design mockups, not a functional website. Contract, tokenomics, legal and official social destinations are still placeholders.
